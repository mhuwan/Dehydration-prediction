# 💧 Dehydration Prediction System

ระบบทำนายภาวะขาดน้ำ (Dehydration Prediction) โดยใช้ **Support Vector Machine (SVM)**
วิเคราะห์ข้อมูลสุขภาพเพื่อประเมินความเสี่ยง พร้อม UI สวยงามแบบ Minimal Modern

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.36-red)
![SVM](https://img.shields.io/badge/ML-SVM-green)

## ✨ Features

- 🤖 **SVM Model** - Support Vector Machine สำหรับ classification
- 📊 **Dashboard** - แสดง metrics, confusion matrix, correlation heatmap
- 💧 **Real-time Prediction** - ทำนายทันทีจาก input
- 🎨 **Modern UI** - Minimal design โทนสีฟ้า พร้อม animations
- 📱 **Responsive** - รองรับทั้ง Desktop และ Mobile
- ⚡ **Fast Loading** - ใช้ caching สำหรับ data และ model
- 🚀 **Deploy Ready** - พร้อม deploy บน Streamlit Community Cloud

## 🛠️ Tech Stack

- **Python 3.10+**
- **Streamlit** - Web framework
- **Scikit-learn** - Machine Learning (SVM)
- **Pandas / NumPy** - Data processing
- **Plotly** - Interactive visualization
- **Kaggle API** - Dataset download
